Inside LLM Inference, Drawn From Real Runs of Small Public Models

Paul Wu, github.com/SomethingObvious

Abstract

A small model guesses the next four tokens and a big model checks all four in one forward pass. Guesses up to the first miss are kept, and the big model adds one token of its own. With greedy decoding the text is exactly what the big model writes alone. In the recorded run in Figure 1 that takes 16 big-model passes instead of 48. Figure 2 shows real router choices inside a mixture-of-experts model, and Figure 3 shows why a matrix multiply leaves part of a GPU idle.

Mixture-of-Experts Routing

IBM Granite 3.0 1B-A400M has 32 experts in each of its 24 layers, and a small router sends every token to 8 of them. Figure 2 shows the router's real decisions from one forward pass over each sentence. Pick a sentence, then hover or tap its tokens.

GPU Waves

A matrix multiply splits its output into tiles, and the GPU runs one tile per SM at a time. When the tile count isn't a multiple of the SM count, the last wave runs with part of the chip idle. Drag N and watch the efficiency in Figure 3 saw up and down.

The lower plot sweeps N for the current M, tile and GPU. Each drop is a new, nearly empty last wave. Kernel libraries fight this with other tile shapes, split-K and persistent kernels.
