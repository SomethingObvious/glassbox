# The Page's Type

These are [Libre Caslon Text](https://github.com/thundernixon/Libre-Caslon) and [Public Sans](https://github.com/uswds/public-sans), each in regular and bold, in the Latin and extended Latin subsets that Google Fonts serves. The page uses no italics, so there are none here.

They are in the repo so that the page can load them ahead of its first frame, with no trip to a font service first. Text set in a stand-in face wraps differently, and it would be seen to move when the real one arrives.

Both families are under the SIL Open Font Licence 1.1, in `OFL-libre-caslon-text.txt` and `OFL-public-sans.txt`.
